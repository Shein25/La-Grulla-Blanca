# Seis cadenas adaptativas T0→T4 — cierre humano v0.1

Fecha de ratificación: 2026-10-01.

Este bloque congela las cadenas adaptativas de seis monstruos repetibles:

- sapo_ceniza
- escarabajo_hierro
- pez_lunar
- anguila_estelar
- devorador_niebla
- halcon_tormenta

## Regla de cierre

T0, T1, T2, T3 y T4 quedan human-ratified y congelados.
No existe T5.

T2 reconoce sólo categorías observables recientes (2 de 2 acciones efectivas).
T3 exige patrón confirmado + interacción causal con T1 y responde con un
paquete del ataque básico T0 de la instancia.
T4 reutiliza la técnica T0 congelada; no aumenta sus números.

## Criterio baseline-relative

El marcador de 50 pp sigue siendo diagnóstico. No bloquea automáticamente
un tier adaptativo si el T0 pareado ya presenta esa sensibilidad. Las alarmas
duras (>75 pp, timeout >2%, identidad ausente) siguen vigentes.

Sapo Ceniza y Escarabajo de Hierro fueron además medidos contra su T0 con la
misma matriz de roots/loadouts/policies. La adaptación no creó la asimetría
observada.

## Guardas

- no main / no merge como parte de este cierre;
- Rata T0–T4 no se modifica;
- unique:true no entra en estas cadenas;
- no target win-rate;
- no inspección de root/build oculto;
- no T5;
- cualquier reapertura exige decisión humana explícita.
