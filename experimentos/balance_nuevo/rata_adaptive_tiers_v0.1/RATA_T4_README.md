# Rata T4 — Mordisco Frenético LAB

T0–T3 están cerrados y ratificados.

## Identidad preservada

```text
Mordisco Frenético
físico
instintivo
basado en 2d4 canónico
familia multi-hit
```

T4 no reemplaza Reflejo ni el reconocimiento. La integración inicial es:

```text
T2 decide SURVIVAL → Reflejo normal
T2 decide BASIC:
    T4 listo   → Mordisco Frenético
    T4 en CD   → BASIC normal
```

Así T4 agrega una salida ofensiva sin destruir T1–T3.

## Fase A — geometría

Fijos:

- precisión independiente por hit;
- crítico independiente por hit;
- CD5;
- cada hit pasa por DEF plana y absorción por separado;
- dados base 2d4.

Candidatos:

```text
CONTROL_1X100  = 1 × 100% de 2d4
FRENZY_2X050   = 2 ×  50% de 2d4
FRENZY_2X075   = 2 ×  75% de 2d4
FRENZY_3X050   = 3 ×  50% de 2d4
```

Los scalars son hipótesis de laboratorio, no números canónicos.

La comparación 2×0.75 vs 3×0.50 mantiene la misma expectativa bruta 1.5×,
pero cambia cuántas veces actúan DEF y absorción.

Después de cerrar esta fase se estudian precisión/crítico y recién al final
cooldown.

No existe T5.
